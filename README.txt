SALITREENI PWA – KÄYTTÖÖNOTTO

Sisältö:
- index.html: sovellus
- manifest.webmanifest: PWA-asetukset
- sw.js: offline-välimuisti
- icons/: sovelluskuvakkeet

KÄYTTÖ:
1. Julkaise tämän kansion sisältö HTTPS-palvelimella (esim. GitHub Pages, Netlify tai oma webhotelli).
2. Avaa julkaistu HTTPS-osoite iPhonen Safarissa.
3. Paina Jaa -> Lisää Koti-valikkoon.
4. Varmista, että "Avaa verkkosovelluksena" on päällä, ja paina Lisää.

HUOM:
- PWA-asennus vaatii HTTPS-julkaisun (localhost on kehityskäytössä poikkeus).
- Tiedot tallentuvat paikallisesti kyseisen sovelluksen selaintallennukseen.
- Historia ei synkronoidu automaattisesti laitteiden välillä. Vie varmuuskopio Historia-välilehdeltä.
- Sovelluksessa on oletuksena 3 tyhjää sarjaa per liike. Sarjamäärää voi muuttaa.
